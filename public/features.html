Satu backend, banyak endpoint — siap dipakai.

Justice API adalah REST API berbasis Express.js dengan format response yang konsisten, sistem tier & rate limit per client, dan panel admin buat nambah endpoint baru tanpa deploy ulang.

Lihat Dokumentasi → Masuk dengan Google/GitHub

Dokumentasi & playground sekarang butuh login. Klik "Lihat Dokumentasi" dan masuk pakai akun Google atau GitHub kamu — gratis, gak perlu daftar API key buat sekadar liat-liat docs.

Kenapa Justice API

Dibikin buat gampang dipakai & gampang dikembangin

GET

Endpoint siap pakai

Mulai dari YouTube Search — cari video berdasarkan kata kunci lewat satu request REST, response-nya JSON yang konsisten.

⇄

Format response konsisten

Semua endpoint balikin bentuk { status, data / error } yang sama, jadi gampang di-parse di sisi client apapun bahasanya.

⚡

Rate limit per tier

Free 100 req/jam, Premium 1000 req/jam, Admin unlimited — dihitung per client (API key/IP), bukan satu kuota global buat semua orang.

＋

Panel admin scaffold

Tambah, edit, atau hapus endpoint baru langsung dari panel admin — kode di-generate & diterapkan tanpa perlu restart manual atau deploy ulang.

🔑

Manajemen API key

Bikin, cabut, dan atur tier tiap client dari panel Clients — key baru langsung aktif tanpa restart server.

🔒

Login Google/GitHub buat Docs

Akses ke halaman dokumentasi & playground sekarang digerbang login OAuth — biar kejelasan siapa yang mengakses docs kamu.
